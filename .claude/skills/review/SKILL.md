# Review – revisit weak topics

## Steps

1. Read `learning/progress.md`, `learning/weak-topics.md`,
   `learning/quiz-history.md` and the `domains/*/README.md` status tables.

2. Give a short progress report:
   - Sections Taught vs Understood per domain (with exam weightings).
   - Open weak topics, oldest / most repeated first.
   - Recommended next step.

3. Ask the user which weak topic to review (or pick the top one).

4. Review using **active recall first**: ask the user to explain the concept
   in their own words before re-teaching. Then correct and fill gaps briefly —
   do not repeat the full lesson.

5. Finish with 1–2 new scenario questions on that topic (follow `/quiz` rules:
   no answers before the user responds), then record results exactly as the
   quiz skill does.
